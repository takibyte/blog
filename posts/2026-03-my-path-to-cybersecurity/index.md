## The plan

Study for CompTIA Network+ and Security+. Whilst working towards attaining these certs, work towards the following projects / lab ideas.


1. Build a cybersecurity homelab



2. Network traffic analysis with Wireshark



3. Recon and port scanning (Nmap + Python script)



4. Firewall configuration & testing (pfSense or iptables)



5. Vulnerability scanning & basic assessment



6. Basic cryptography implementation



7. Simple intrusion detection / SIEM setup
