
# takibyte homelab

I started takibyte as a place to document my path into cybersecurity, most of this is for my own learning and reference. If it's useful to someone else going through similar certs, CTF rooms, and homelab experiments, that's a bonus, and would make me happy!

Most of the projects and logs that end up here start as a TryHackMe room, a homelab experiment, or a concept from studying that I thought might be useful to write about.

This site is statically built from markdown with a custom script, no frameworks.
